# 指尖飞舞 - 打字练习应用

一个基于Vue 3的现代化打字练习应用，最初为8岁儿童设计，但同样适用于所有希望提升打字技能的用户（儿童、青少年、成人）。

## 🌟 核心特性

### ✅ V1.0 已实现功能

#### 🎯 游戏体验
- **3秒准备倒计时** - 给用户充分准备时间，避免措手不及
- **队列出栈机制** - 创新的字母序列管理，永远不会出现滚动偏移或溢出
- **智能居中显示** - 当前字母位于屏幕视觉焦点，长时间使用不疲劳
- **200字符序列** - 充足的内容，无需中途补充
- **实时动态反馈** - 正确/错误即时音效和视觉反馈

#### ⌨️ 键盘功能
- **完整QWERTY虚拟键盘** - 真实键位布局展示
- **当前键位高亮** - 黄色脉动高亮，橙色指示器
- **F/J盲文标记** - 符合真实键盘设计的盲文引导线
- **空格键优化** - 280px加长设计，贴合真实使用习惯
- **键盘音效** - Web Audio API生成清脆正确音/低沉错误音

#### 📊 计分系统
- **实时计分** - 正确+10分，错误-5分
- **准确率统计** - 动态计算正确率百分比
- **连击机制** - 连续正确触发连击，显示当前连击数
- **历史最高分** - 本地存储，激励持续进步
- **完整游戏统计** - 正确/错误次数详细记录

#### ⚙️ 个性化配置
- **大小写模式**：
  - 默认：忽略大小写，显示大写字母（视觉清晰）
  - 高级：区分大小写，50%随机大小写
- **音效开关** - 可自由开启/关闭按键音效
- **响应式设计** - 完美适配手机、平板、桌面设备

### 🆕 V1.1 新增功能

#### 📝 文本导入系统
- **多种导入方式**：
  - 上传文件：支持 .txt、.md 格式（拖拽或点击上传）
  - 粘贴文本：直接粘贴任意文本内容
- **智能文本处理**：
  - 自动提取字母和空格，保留原始大小写
  - 自动转换换行符为空格
  - 过滤标点符号和数字（专注字母练习）
- **两种练习模式**：
  - **纯文本模式**：仅使用导入的文本（不足200字符时自动补充随机字母）
  - **混合模式**：70%文本内容 + 30%随机字母，增加挑战性
- **实时验证**：即时显示文本有效性、字符统计和预览
- **大小写智能匹配**：
  - 导入内容保留原始大小写显示
  - 根据配置决定是否忽略大小写匹配
  - 随机内容默认大写显示（视觉清晰）

### 🎨 视觉设计亮点

#### 用户体验优化
- **稳定布局** - 固定容器高度，防止准备阶段布局抖动

#### 儿童友好特性
- **温暖配色** - 蓝色主调(#4A90E2)，橙色强调(#F5A623)
- **趣味动画** - 脉动、渐变、发光效果吸引注意力
- **清晰引导** - "待敲击字母"等友好提示文案
- **即时反馈** - 正确/错误立即视觉和听觉反馈

## 🎯 使用说明

### 开始练习

1. **启动应用** - 页面加载完成，显示"开始练习 (Enter)"按钮
2. **点击开始** - 进入3秒倒计时准备阶段
3. **准备阶段** - 黄色倒计时显示，字母序列已生成但不可操作
4. **开始练习** - 倒计时结束，时间开始2分钟倒计时
5. **输入练习** - 按照字母序列提示，在真实键盘上按下对应键位
6. **查看结果** - 2分钟后显示详细统计数据和历史最高分

### 键盘操作

- **Enter键** - 开始/重新开始游戏
- **字母键** - A-Z对应输入
- **空格键** - 空格字符输入（␣符号显示）
- **ESC键** - 未来版本计划支持暂停功能

### 计分规则

- **正确输入** - +10分
- **错误输入** - -5分（最低0分）
- **准确率** - 正确次数 / 总输入次数 × 100%
- **连击数** - 连续正确输入次数，错误时重置为0

### 配置选项

点击"⚙️ 设置"按钮进入配置：

#### 大小写模式
- **忽略大小写**（推荐新手）
  - 显示：大写字母（A, B, C...）
  - 输入：a 或 A 都正确
  - 适合：初学者，专注于键位和节奏

- **区分大小写**（进阶模式）
  - 显示：随机大小写（50%大写，50%小写）
  - 输入：必须严格匹配
  - 适合：希望提升精确度的用户

#### 音效设置
- **启用音效** - 正确音（清脆上扬）、错误音（低沉下落）
- **关闭音效** - 纯视觉练习模式

## 🏆 开发历程

### V1.0 开发阶段

#### 阶段一：初始问题修复（30分钟）
- 修复结果弹窗总分显示空白
- 优化字母间距：3px → 1px
- 调整虚拟键盘：正方形键位、加长空格键
- 添加F/J键盲文标记线

#### 阶段二：动态滚动实现（45分钟）
- 设计滚动逻辑：currentIndex + transform
- 实现字母左移动画
- 解决左侧溢出问题：添加leftMargin

#### 阶段三：自动化测试（30分钟）
- 搭建Puppeteer测试框架
- 编写9个E2E测试用例
- 修复测试超时问题

#### 阶段四：体验优化（30分钟）
- 序列长度：50 → 200字符
- 动画速度：0.3s → 0.15s
- 添加3秒准备倒计时
- 空格键长度：200px → 280px

#### 阶段五：大小写逻辑（20分钟）
- 默认：显示大写字母
- 区分大小写：50%随机大小写

#### 阶段六：根本性重构（60分钟）
**重大突破：队列出栈模式**
- 移除currentIndex概念
- shift+push机制替代滚动逻辑
- 彻底解决溢出/偏移问题
- 代码从复杂→简洁，性能大幅提升

#### 阶段七：视觉优化（15分钟）
- 添加150px左侧padding，居中显示
- 固定controls容器高度，防止抖动
